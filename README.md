# cs50-scratch-animation
My First CS50 Scratch Project- an interactive animation created using visual programming concepts

CS50 Scratch Animation Project

Overview

This project was developed as part of Harvard University's CS50 Introduction to Computer Science course.

It is an interactive animation created using Scratch, incorporating visual programming concepts and logical sequences.

Objectives

- Understand programming fundamentals.
- Implement events and conditional logic.
- Explore animation and interactive design.
- Develop problem-solving skills.

Concepts Used

- Events
- Loops
- Conditional statements
- Variables
- Sprites and animation

How to Run

1. Download the ".sb3" project file.
2. Visit https://scratch.mit.edu/.
3. Open the Scratch editor.
4. Select File → Load from your computer.
5. Choose the downloaded project file.

Learning Experience

This project helped me understand how programming logic can be used to create interactive experiences and strengthened my understanding of computational thinking.
